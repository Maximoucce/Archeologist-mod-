# ![icon](assets/1x/Icon1x.png) Archeologist Mod

This mod is a test.<br>
*I'm looking for feedback on balance, localization and sprites so feel free to do so !* 🙏

# **3 New Jokers :**
<img width="395" height="180" alt="2379780_2075" src="https://github.com/user-attachments/assets/69d16147-62b2-473b-b5cd-cab54d6e08ab" /><br>

1. **Archeologist *(Rare)*** : Has the same effect as blueprint or brainstorm, but for cards that were at it's position at the end of last run. <br>⚠️*It sometimes doesn't copy some jokers or can crash the game*
2. **Brush *(Common)*** : when first hand is a single **Sandy Card**, remove the sand and turn it into a new enhanced card (*enhanced + seal + edition*) <br>➡️*The brush pixel art comes from the **Faithful java 64x texture pack** for Minecraft [get it here : https://faithfulpack.net](https://faithfulpack.net)*

3. **Sandy Joker *(Uncommon)*** : Multiplies the blind size by X0.02 for each **Sandy Card** in your full deck (starting at X1). 

# **A New Enhancement :**
![icon](assets/1x/sandfinal.png)
<br> **Sandy Card** : Multiplies the blind X0.95 when the card is scored.

# **2 New Tarots :**
<img width="260" height="174" alt="2379780_2086" src="https://github.com/user-attachments/assets/4222fd68-0edd-40ae-8ae0-e734ae5a0f28" /><br>

1. **Desert** : Turns 2 selected cards into **Sandy Cards**.
2. **Excavation** : 3 in 6 chances to receive 50$, but triggers the ~~*Pharao's Curse*~~ if it fails. *(something seems to increase your odds...)*

# **A New Spectral :**
<img width="130" height="171" alt="2379780_2080" src="https://github.com/user-attachments/assets/250b54e5-920a-4bda-8925-7870cb433071" /><br>
**Artefact** : Adds a **Scarab Seal** to a selected card.

# **A New Seal :**
<img width="68" height="68" alt="SCARR11" src="https://github.com/user-attachments/assets/d00d41b7-b7df-4a0f-9e92-b6bd5e77003e" /><br>
**Scarab Seal :** Has different scoring effects depending on position in played hand :
| Position | Effect |
| ----------- | ----------- |
| First Position | +20 Chips and +3 Mult |
| Middle Positions | +2$ |
| Last Position | X1.3 Mult |

# **A New Blind :**
<img width="64" height="64" alt="fossilEN" src="https://github.com/user-attachments/assets/756ebe70-f99e-4544-97e7-dda2a3ea0e0e" /><br>
**The Fossil** : Beating it with flame effects will break it ( -15$ at the end of the round).

# **2 New Stakes :** *(past Gold)*
![icon](assets/2x/staketest3.png)
1. **Pale Green Stake** : Shop can have **Washed Jokers**.
2. **Brown Stake** : Shop can have **Faulty Jokers**.

# **2 New Stickers :**
<img width="40" height="40" alt="223322" src="https://github.com/user-attachments/assets/121b19d4-94cc-4562-b91c-4134a3afc946" />  **Washed** : All the values in the config table and price of the joker get randomized between **X0.5** and **X1.3**.<br>
<img width="40" height="40" alt="233211" src="https://github.com/user-attachments/assets/dedb81b8-c4c7-44f4-94ec-a4ae8215beab" />  **Faulty** : 1 in 5 chances to be debuffed at the beginning of the round.

# **A New Deck :**
![icon](assets/2x/Museeidee.png)<br>
**Museum Deck** : After beating a Boss Blind, rewards you based on the rarity of each of your Jokers. But you earn **no interest**.<br>
| Rarity | Reward per Joker |
| ----------- | ----------- |
| Common | 1$ |
| Uncommon | 3$ |
| Rare | 5$ |
| Legendary | 1 spectral card |

# **A New Tag :**
![icon](assets/2x/tagline2x.png) **Review Tag** : Gives 1 retrigger to ALL scored cards and in held in hand abilities for the next round (like : dusk + mime).<br>

# **2 New Vouchers :**
<img width="226" height="174" alt="2379780_2085" src="https://github.com/user-attachments/assets/bb312ee6-4f8c-4935-b85d-f0c04780f367" /><br>
* *(lvl 1)* **Shovel** : Every card played when at least 1/3 of the deck is drawn give 1$.<br>
* *(lvl 2)* **Excavator** : Gives +1 discard. Every card played when at least 2/3 of the deck is drawn give 1$.
